מידע ותכנון מוזיקלי לאירוע

חתונה חרדית יכולה לשלב מוזיקה חסידית ויהודית עם מסורות עדתיות שמחברות את המשפחות לרחבה. כאשר משלבים הרקדה תימנית חשוב לבחור את הקטעים המוכרים לקהל, להבין את המקום שלהם בתוך הערב ולתאם מראש עם הזוג וההורים. כך המוזיקה העדתית מקבלת רגע מרכזי בלי לפגוע ברצף של הריקודים.

הסרטון מחצר המלכה בצומת כנות מציג הרקדה תימנית מתוך חתונה חרדית עם DJ ATLANTIS אלי מועלם. הקצב, התנועה והשמחה ברחבה ממחישים כיצד מוזיקה שמחוברת למסורת המשפחתית יכולה לאחד את הקהל. דיג׳יי חרדי צריך לדעת להוביל את המעבר אל ההרקדה ולחזור ממנה לסגנון הבא באופן טבעי.

לפני האירוע מגדירים את הניגונים, המוזיקה החסידית והשירים היהודיים החשובים, לצד מוזיקה תימנית, מזרחית וסגנונות נוספים שהזוג בוחר. בזמן אמת אלי מועלם בודק את תגובת האורחים ומשנה את הקצב לפי הרחבה. המטרה היא לשמור על אופי החתונה ועל כללי הקהל, ובמקביל לתת לכל משפחה את הרגע המוזיקלי שלה.

זוגות שמחפשים תקליטן לחתונה חרדית או מוזיקה תימנית לחתונה יכולים לצפות בתיעוד ולראות את השילוב באירוע אמיתי. בשיחת ההתאמה מדייקים את סדר הקטעים, את גבולות הסגנון ואת הבקשות המשפחתיות, כדי ליצור רחבה מכבדת, שמחה ומגוונת.
